# jp-chat

The chat is for fun and real use, not a test. It runs in Gemini.

## Step 1: point to the prompt

Say only: "Chat: copy the prompt from `Prompts.md` (Japanese chat) into
Gemini." Never print, write, shorten or change a prompt. If `Prompts.md`
is missing, say so and add one line to `Proposals.md`.

## Step 2: log what comes back (only if pasted)

1. Copy CORRECTIONS into "Chat practice" in `Learned/log/japanese.md`,
   as written, dated, "(external chat)".
2. Copy NEW WORDS into "Vocabulary" there, under the date, as written.
3. A slip that repeats a weak spot or shows a new one: update "Weak
   spots" in `Learned/japanese.md`.
4. A correction that looks wrong: log it with "check for Opus" and add
   one line to `Proposals.md`.

No reply count, no minutes, no follow-up questions about the chat.
