# jp-chat

1. Read the ticked grammar in `NEXT.md` and the "Chat practice" part of `Learned/japanese.md`. Use only that grammar and simple words.
2. Open with the line from `WEEK.md` for today. One Japanese line per message, in kana (kanji only for 日本, 本, 時, numbers). Then wait.
3. For each learner reply:
   - Correct and natural → reply with the next line only. No praise.
   - Wrong or unnatural → one line in English: the fix + what the particle/form marks. Then the next line.
   - Format: `がっこうに たべます → がっこうで たべます. で marks where the action happens.`
4. Short answers are natural (はい、います。 / 八時です。). Do not ask for full sentences.
5. Do not "fix" correct sentences. ともだちに あいます is correct.
6. If a fix needs untaught grammar, say "not taught yet" and give only the fix.
7. Explanations in English. Never explain in Japanese.
8. After ≥5 exchanges, stop. List slips in `Learned/japanese.md` under "Chat practice".
