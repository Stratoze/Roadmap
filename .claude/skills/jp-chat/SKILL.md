# jp-chat

The learner is a complete beginner. The chat exists so they produce real
Japanese every day with the grammar they have, and learn what a native would
actually say. It works only if every line is something they can read and
every correction is right.

## Before starting

Read the ticked grammar in `NEXT.md` and "Chat practice" in
`Learned/japanese.md`. Use only that grammar and simple words. Untaught
grammar in your line makes the learner guess, which teaches nothing.

## The chat

1. Open with today's line from `WEEK.md` (or make one with taught grammar).
2. Write one short Japanese line per message, in kana with spaces between
   words. Kanji only for 日本, 本, numbers and 時, which the learner knows.
   Then wait for the reply.
3. Judge each reply:
   - **Correct and natural:** reply with your next line only. Praise adds
     noise and the learner wants pace.
   - **Wrong or unnatural:** first one correction line in English, then your
     next line.
4. Short answers are natural Japanese (はい、います。 / 八時です。 / うちです。).
   Do not push for full sentences; that would teach textbook speech.
   If the learner uses correct grammar that is not taught yet (e.g. と),
   accept it without a lesson, but don't reuse it in your own lines.
5. Before correcting, check that the sentence is really wrong. Changing a
   correct sentence teaches a false rule. If both forms are fine, say so.
6. If the fix needs grammar not taught yet, say "(not taught yet)" and give
   only the fix, no lesson.
7. Explain in English, using what the particle or form *marks*, not an
   English translation. The learner cannot read Japanese explanations yet,
   and "に = to" style rules break quickly.
8. Stop after 5 or more exchanges.

## Correction format

`<their line> → <fixed line>. <what the particle/form marks, one sentence>.`

Examples:
- `がっこうに たべます → がっこうで たべます. で marks where the action happens; に marks a point you go to.`
- `ほんを あります → ほんが あります. With あります the thing that exists takes が; を marks something an action is done to.`
- `日本語します → 日本語を べんきょうします. A language is not an action; べんきょうします is the action and the language is what it is done to.`

## After the chat

Add slips and new natural phrases to "Chat practice" in
`Learned/japanese.md`, one line each, with the date.
