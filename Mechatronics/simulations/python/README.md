# Python Simulations

Use for control, dynamics, filtering, and data-analysis experiments.

## Environment (set up 2026-09-14)

- Project venv: `Mechatronics/simulations/python/.venv` (gitignored) - python 3.14.7.
- Installed: jupyterlab 4.6.3, numpy 2.5.3, scipy 1.18.1, pandas 3.0.5, matplotlib 3.11.2.
  Note: pandas 3.x → Copy-on-Write is default (differs from older tutorials).
- Run JupyterLab from this directory:
  `cd Mechatronics/simulations/python && .venv/bin/jupyter lab`

Naming:

```txt
YYYY-MM-DD_short_question.py
YYYY-MM-DD_short_question.md
YYYY-MM-DD_result_plot.png
```
