## Q1 — Tip position

Given: L1 = 10 cm, L2 = 5 cm, θ1 = 30° from world x-axis, θ2 = 60° measured relative to link 1.

```
tip of l1 = 10 cm vector, 30 deg ccw relative to the x axis.
tip of l2 = 5 cm vector, 60 deg relative to tip of link 1 → 90 deg relative to the x axis.
cos(30) = x/10 gives x of link 1, sin(30) = y/10 gives y.
second link is parallel to the y axis, so x stays the same as tip of link 1, y + 5 cm.
```

Result: **X = 8.66 cm, Y = 10 cm** ✓ (converted θ2 to world frame instead of plugging in 60°)

## Q2 — World vs. link frame

a) Joint-2 encoder reads 60° — measured in which frame?

```
link frame, relative to the angle of link 1.
```

b) Rotate the entire mounting base 90° CCW without moving any joint — what happens?

```
encoder readings stay the same;
the tip's world coordinates have a 90 deg rotation matrix applied to them.
```

## Q3 — Vector diagram (no formulas)

```
l1: from (0,0), 30 deg ccw relative to x, 10 cm out.
l2: from previous point's tip, straight up, 5 cm.
resultant: from (0,0) to tip of l2.
because the tip's coordinate is just the sum of the vectors' xs and ys.
```

Head-to-tail construction, angles marked against the correct references, addition justified by components — not by recalling an FK equation.

## Q1 — Third link (vector addition)

Given: L1=10 cm, L2=5 cm, L3=3 cm, θ1=30° world, θ2=60° rel to L1, θ3=-30° rel to L2.

```
a) World angles: L1 30°, L2 =30+60=90° (straight up), L3 =90-30=60° NE.
   b) Tip = Σ Li·[cosθi_world, sinθi_world] head-to-tail:
   L1: 10 cm @30°, L2: from tip of L1 straight up 5 cm, L3: from tip of L2 3 cm @60°
   X =10·cos30 +5·cos90 +3·cos60 =8.660+0+1.500=10.16 cm (~10.1 mental)
   Y =10·sin30 +5·sin90 +3·sin60 =5.000+5.000+2.598=12.60 cm (corrected from 12.4 slip)
   cos30=√3/2≈0.866, sin30=0.5, cos60=0.5, sin60≈0.866
```

## Q2 — Rotate the base

```
a) Encoder readings unchanged — measured in link frame, not world.
   (gravity/external irrelevant; encoder is joint-relative)
b) 90° CCW: P' = (-y, x) = (-12.60, 10.16) cm
c) -90° CW: P' = (y, -x) = (12.60, -10.16) cm — corrected from (x,-y) flip
```

## Q3 — Change reference frame

```
a) F' origin at world (2,3), axes rotated 30° CCW from world:
   P_F' = R(-30°)·(P_world - [2;3]), R(-30)=[[cos30, sin30],[-sin30, cos30]]
   (subtract translation, then un-rotate; inverse of P_world = R(30)·P_F' + t)
b) Pure translation to (2,0) (no rotation): P_F' = (10.16-2, 12.60-0) = (8.16, 12.60) cm
   Lengths preserved; rotation requires matrix, translation is subtraction.
```

## Q4 — Dot product as projection

```
Vectors: a=L1 (10 cm @30°), b=L2 (5 cm @90°), Δθ=60°
a) a·b = |a||b|cosΔθ =10·5·cos60 =25 cm²
   = |a|·(projection of b onto a direction) = |b|·(projection of a onto b direction)
   Physical: signed length of one vector's shadow onto the other's axis, scaled by the other's magnitude.
b) >0 when Δθ<90° (acute, shadows same direction), =0 when ⊥90°, <0 when Δθ>90° (obtuse, shadows oppose).
   (corrected from "left of a / right-hand rule")
c) Straight elbow Δθ=0 → cos0=1 → a·b=|a||b|=50 maximum. Means full alignment → maximum reach along a's axis.
```
