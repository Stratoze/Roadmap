## Q1 — Tip position

Given: L1 = 10 cm, L2 = 5 cm, θ1 = 30° from world x-axis, θ2 = 60° measured relative to link 1.

```
tip of l1 = 10 cm vector, 30 deg ccw relative to the x axis.
tip of l2 = 5 cm vector, 60 deg relative to tip of link 1 → 90 deg relative to the x axis.
cos(30) = x/10 gives x of link 1, sin(30) = y/10 gives y.
second link is parallel to the y axis, so x stays the same as tip of link 1, y + 5 cm.
```

Result: **X = 8.66 cm, Y = 10 cm** ✓ (converted θ2 to world frame instead of plugging in 60°)

## Q2 — World vs. link frame

a) Joint-2 encoder reads 60° — measured in which frame?

```
link frame, relative to the angle of link 1.
```

b) Rotate the entire mounting base 90° CCW without moving any joint — what happens?

```
encoder readings stay the same;
the tip's world coordinates have a 90 deg rotation matrix applied to them.
```

## Q3 — Vector diagram (no formulas)

```
l1: from (0,0), 30 deg ccw relative to x, 10 cm out.
l2: from previous point's tip, straight up, 5 cm.
resultant: from (0,0) to tip of l2.
because the tip's coordinate is just the sum of the vectors' xs and ys.
```

Head-to-tail construction, angles marked against the correct references, addition justified by components — not by recalling an FK equation.
