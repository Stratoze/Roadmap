# Milestone evidence hub

Worked solutions live here, one file per milestone: `0.x-slug.md`.
Canonical specs stay in [[Mechatronics/milestones/00_foundations|00_foundations]] — this folder is evidence, never the assignment.

## Convention (frozen)

- `Attempt:` blocks are frozen at write time (date + open/closed-book noted). `Correction:` blocks are dated + sourced. Never edit an Attempt into correctness — hindsight goes in Correction.
- Every numeric result carries units + tolerance/uncertainty. A bare number is not a result.
- Physical/toolchain passes link their artifact (photo, hex, commit hash, capture path).
