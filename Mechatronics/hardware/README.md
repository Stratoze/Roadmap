# Hardware

Use for physical lab state that is not purely CAD or PCB.

Examples:

- inventory
- wiring diagrams
- pin maps
- connector notes
- test rigs
- fixture notes
- motor/sensor bench setup

Suggested folders:

```txt
hardware/
├── inventory.md
├── wiring/
└── test_rigs/
```

If it answers "what is physically connected to what?", it probably belongs here.
