# Personal Learning System — Mechatronics Engineering

This is a **public learning journal**, not a polished portfolio.

It documents my self-directed mechatronics curriculum using a hypothesis-driven
learning loop. Every milestone is verified via Git tags (`git tag -l`).

- **Start here:** [Mechatronics/ROADMAP.md](Mechatronics/ROADMAP.md)
- **Evidence:** `git log --oneline --decorate` or browse tags
- **Method:** [_system/How to Learn.md](_system/How%20to%20Learn.md)
- **Status:** Active, in progress, always incomplete

The final portfolio deliverable (Phase 5) will be a separate, curated repository.
This repo is the process. The portfolio is the product.
