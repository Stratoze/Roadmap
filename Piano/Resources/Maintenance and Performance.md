# Maintenance and Performance

## Maintenance rotation (Engram)

Engram schedules all piece review, including "review this song today"
(topic `piano`, via `/review-loop`). Its interval math is receipt-based, so
treat its suggestions as the schedule, not heuristics.

### Card types

| Type | Example |
| --- | --- |
| Whole-piece | Perform [piece], one take, no stopping. |
| Section | [piece], mm. 17–24: one cold attempt at target tempo. |
| Start-point | Begin [piece] at the development or B section. |
| Musical | [piece], opening: demonstrate voicing, pedaling, phrase direction. |
| Memory | Play [piece] from memory starting at structural point 3. |

### Review modes

Practice mode:

- test the card once before practicing
- work only on the identified weakness
- retest once at the end

Performance mode:

- one uninterrupted take
- no metronome unless testing steady tempo
- no stopping
- record
- do not immediately chase a better take
- write 1–3 observations

### Grading

| Grade | Meaning |
| --- | --- |
| Again | Could not begin, major memory failure, or needs to return to learning |
| Hard | Completed, but with several hesitations or excessive effort |
| Good | Complete and musically coherent, minor problems only |
| Easy | Secure cold performance, good control, successful start points |

Reviews are scheduled by Engram; the safety net below still applies on top.

### Workload

- Limit by time, roughly 5–15 min, not card count.
- Review long pieces as sections.
- Archive pieces you no longer intend to keep performance-ready.
- Safety net: no active piece goes untouched longer than roughly 2 weeks, regardless of scheduled interval.
- Independently of reviews, play every active polishing piece through once each week.

### Interleaving

When reviewing multiple pieces, rotate between them rather than playing one piece three times in a row.

Interleaving matters most for pieces that are similar or easily confused:

- same key
- similar patterns
- same composer or period

Very different pieces do not benefit much; blocking is fine.
Brand-new Day-1 learning does not need interleaving either.

## Recording and Self-Assessment

Do not record every repetition.

Record:

- one weekly performance take
- a baseline when beginning a significant piece
- checkpoints and final performances
- occasional short diagnostic clips
- monthly video for posture, tension, and movement

### Self-review rubric

Score 0–2 each.

| Dimension                                      | 0 = needs repair | 1 = inconsistent | 2 = secure |
| ---------------------------------------------- | ---------------- | ---------------- | ---------- |
| Notes and rhythm                               |                  |                  |            |
| Pulse, continuity, recovery                    |                  |                  |            |
| Tone, voicing, articulation, phrasing, pedaling|                  |                  |            |
| Physical ease and control                      |                  |                  |            |

### App limitations

Piano Marvel and similar apps assess note and rhythm accuracy only.
They do not assess dynamics, articulation, tone, pedaling, or musicality.

Piano Marvel microphone mode is iOS-only and less reliable for complex polyphony or fast passages.

Use app scores as one data point for accuracy.
Everything else uses your rubric, recordings, and external feedback.
Log each review with [[_templates/piano/Recording Review|Recording Review]] — one fix carries to next week.

## Performance Simulation and Memorization

### Weekly performance simulation

Once per week:

- address an imaginary audience
- play start to finish
- no stopping
- record, video preferred
- review only after finishing
- score with the rubric
- log it
- move on

Do not immediately chase a better take.

### Memorization security

- Muscle: can you play without looking at your hands?
- Auditory: can you sing it away from the piano?
- Visual: can you see key spots in your mind?
- Analytical: can you describe the harmony and form in words?
- Sleep consolidation: visualize the piece before bed. Overnight replay supports retention; gain is a bonus, not a promise.
- Mental practice: rehearse the piece away from the piano. See it, feel it, hear it.

Muscle memory alone is the most likely to collapse under nerves.
Analytical memory is the safety net.
Build all four from day 1.

### Dual-task performance simulation

Once per month, add a cognitive load to your performance simulation (log it with [[_templates/piano/Recording Review|Recording Review]]):

- Play the piece while counting aloud
- Play while naming the chords
- Play while a metronome plays on off-beats
- Play while a recording of the piece plays slightly out of sync (optional experiment, not a standard — pressure inoculation evidence is thin; performance failure is mostly arousal-driven retrieval collapse, not distraction-overload)

This trains recovery and focus under distraction, which is what real performance demands.

### Pre-performance routine (10 minutes before)

Use the same routine every time so it becomes a trigger for focus.

1. **Body (2 min):** gentle shoulder rolls, arm swings, hand shakes.
   No stretching. Breathe slowly: 4 counts in, 6 counts out, ×5.
2. **Mental (3 min):** close eyes, visualize the opening of each piece.
   Hear the tempo, feel the first notes, see the first page.
   Do not visualize the whole piece — just the entry points.
3. **Physical (3 min):** play the opening 2–4 measures of each piece,
   slowly, with full musical intention. Not a run-through. A "hello."
4. **Practical (2 min):** adjust bench, check pedal, place score if needed,
   silence phone, note the room's acoustics.
5. **Commit:** choose the character of the first piece. One word.
   Then begin. Do not wait to feel ready.
